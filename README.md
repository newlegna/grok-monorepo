# grok-monorepo

Sticky playground for small public tech demos. One app per pick under `apps/<slug>/`.

```
apps/<slug>/          self-contained Bun app (`bun install && bun run dev`)
skills/               vendored planning notes
tracking/seen-bookmarks.json
AGENTS.md
```

Cloud agents only add or update `apps/<slug>/`, open one PR, and attach at least one screenshot and one video of the running app.
